# v0.1.1 — Generic reference and submission diagnostics

The evaluator previously classified one document ID from July as a known
exception, including when evaluating a different month without golden.
This hotfix removes the runtime exception table and ID-based comparison notes.

Every submitted journal entry is checked with the existing general accounting
rules. Missing required partners and other violations remain `ENTRY_RULE`
warnings, regardless of document ID, month or line position. The strict ledger
insertion rules are unchanged.

When golden is explicitly supplied for evaluation, its actual entries are
validated separately using the same rules. Violations produce
`REFERENCE_ENTRY_RULE` warnings, even if the corresponding submitted row is
missing or correct. A defective reference never exempts a defective submission.
Without golden, no reference diagnostics are produced.

The official scorer, its scores and source records are unchanged. The July
example remains in audit documentation and organizer-data tests, rather than
executable exception logic. Report consumers should use the new diagnostic
code; `KNOWN_EXCEPTION` and its ID-based entity notes are no longer emitted.

## Verification

- Synthetic regressions use unfamiliar and reused IDs, multiple months, and
  different line positions without golden.
- Missing supplier partners and unbalanced entries remain visible separately.
- A correct submission against a defective reference reports only the reference
  violation; a defective submission against a correct reference reports only
  the submission violation.
- The original July ZIP produces the unchanged official scores: golden 100.0,
  empty 3.54 and AP-only 36.38, with successful reconciliation.
- The full suite passes 54 tests with the original ZIP; compileall, doctor and
  git diff --check pass.

M1 issue #54 owns evidence-based supplier assignment for advances. M7 issue
#106 owns full execution with golden unavailable and without phase-specific
answer tables. This hotfix detects discrepancies; it does not invent or repair
missing source facts and does not complete those accounting engines.

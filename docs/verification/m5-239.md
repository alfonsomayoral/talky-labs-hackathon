suppressing these IDs, moving their journals to another deliverable or removing
reference-absent cause keys would not satisfy the current policy and output scope.

## Project decision — 2026-10-03

After reviewing the evidence, the user directed the project to proceed without
an exclusion rule and accept the possibility of a defective reference. The
project therefore retains all three transit findings, preserves source, golden
and scorer bytes, and discloses official IC 0.8615. No solver change is required.

#239 is closed as an accepted and documented reference discrepancy. The prepared
organizer question remains available, but an answer is not required to advance
the project. This is a project acceptance decision, not an organizer-confirmed
reference correction. M5 and #159 remain open until the real AP → banks → IC
flow is demonstrated; no improved official score is claimed.
